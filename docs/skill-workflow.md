# SKILL 收藏与连续交接

本迭代使用原有 Python 标准库、SQLite 和界面组件，不安装模型、字体或运行依赖。此文描述开发候选，正式下载版本以 README 下载区为准。

## 收藏、分类、绑定

SKILL 库默认显示“全部技能”卡片，也可切换“我的收藏”和“本项目已绑定”。标题和计数跟随当前范围，未绑定不代表没有技能。来源筛选可展开查看目录及扫描管理，用途筛选保留在上方；内置规范和客户端接入收进“更多”。

从卡片之间的空白处拖动可框选，Ctrl 可切换选中项、Shift 可连续选择；键盘空格切换选择，Enter 打开。选中后显示批量操作。选择外部 SKILL 后点击“收藏”，先核对包内文件数量和容量，再确认复制整个技能目录。原文件保留，只读说明、脚本、参考文件和资源一起保存；不执行脚本，不自动安装依赖。链接、越界、不安全文件与超限包会拒绝复制。

SKILL 与文档预览页可在未选中文字的区域右键“返回列表”，保留打开的标签、未保存正文、搜索及列表页码。编辑区和选中文字仍使用原有复制粘贴菜单。

收藏保留来源和内容摘要。重复收藏相同内容复用版本；来源更新生成另一个版本，不覆盖旧版。绑定项目时固定版本，换端口不会更换或丢失绑定。“版本”中可以检查来源，明确选择把某个收藏版本用于项目。已有旧绑定保留，不擅自复制外部资源；建议收藏后在版本窗口固定版本。

解绑仅解除项目关系，不删除收藏或外部源文件。外部扫描仍按既有边界运行，不为查询或分类全盘扫描。

## 自建文件夹、标签和备注

SKILL 库可直接“新建文件夹”，进入文件夹后可继续创建下级或编辑名称、上级位置。最多 3 层；这是映序中的分类，不搬动 Codex、插件或其他工具的目录。全部技能仍默认可见，文件夹、标签、来源和搜索共同筛选；“查看全部技能”可以清除筛选。

每张卡片的“分类 / 标签 / 备注”可选择文件夹、填写标签和备注；卡片右键也提供相同入口，外部技能无需先收藏。最多 32 个标签，每个 40 字，备注最多 4000 字。名称、说明、路径、标签和备注都可搜索。收藏及其源技能共用一份整理记录，绑定版本和技能正文不变。

框选后“整理所选”可批量归类和追加标签，默认保持各自文件夹和标签，备注分别保留。明确勾选替换标签时才覆盖；替换为空会清空。保存批量整理使用同一事务，任一技能或目标无效时整批不写入。文件夹删除前须先移出成员和子文件夹；隐藏或移除的技能仍保留整理记录，以便恢复。

来源区域的“来源分组”管理扫描位置的组合，区别于个人标签。“用途”继续保留旧收藏的用途分类。Codex 用户技能和 Codex 插件缓存分别登记；插件只按已知 cache/marketplace/plugin/version/skills 层级扫描，缓存中存在技能不代表插件已在 Codex 启用。来源查询、文件夹查询和标签修改不扫描磁盘；启动或主动刷新才扫描，截断或失败时保留已有索引并报告状态。

## 与曜核或客户端接入

“曜核 / 客户端接入”生成显式的本地共享目录及版本清单。有当前项目时仅导出该项目固定版本的收藏；未固定的旧绑定单独报告，不默默改成最新版本。目录内保留完整技能包，可由支持自定义 SKILL 目录的客户端登记。

这一步证明“可读取目录”，不等于客户端已安装、加载或执行。未自动改写曜核或其他客户端配置，未共享写入其他产品数据库。跨产品 COOP-00 公共协议由曜核统一维护，本地收藏清单不是替代协议。不同设备或沙箱无法读取本机目录时，需要另行传递经选择的完整包。

## 首次交接与本轮变化

在 AI 协作中选择稳定的客户端名称和会话名称，填写本轮完整任务。端口不作为身份。新会话使用完整交接；已确认交接过的同一项目、客户端、会话，下一轮比较不可变快照，列出新增、变化、改名/移动、退出本轮选择与项目中已移除的资料。取消选择不等于删除文件。

范围可选项目全部资源或资源区已选条目。快照保存选定资料的元数据及有界文本摘要，不嵌入文件正文或媒体；资料引用仅在目标客户端能访问该设备路径时有效，源文件以后仍可能变化。当前 `.yingxu/PROJECT_CONTEXT.md` 是实时参考，不能作为历史比较基线。

“复制交接”不会推进基线，只有“我已交给该会话”才记录确认；这只是用户交接记录，不宣称 AI 已应用变更。旧快照不能覆盖更新的已确认基线。无法验证历史基线时退回完整交接，也可主动勾选“本轮发送完整交接”。文稿尚未保存时先阻止生成，避免把旧磁盘内容当成最新稿。

## MCP 实时读取

AI 协作页提供“启用本项目 MCP”“关闭 MCP”和“复制 MCP 配置”。每次启动默认关闭，只有明确开启的一个项目可读取；切换工作台项目不会默默改变授权项目。将复制的配置添加到支持自定义 HTTP MCP 与 Authorization header 的本机 AI 客户端，由客户端调用工具。没有自动操作其他软件、发送消息或安装 SKILL；需要 OAuth 自动发现的客户端可能不能使用这份静态本地配置。

服务复用映序当前后台端口的 `/mcp`，绑定本机 127.0.0.1，不新建后台进程、文件监控或常驻轮询。每次调用读取已保存的内容和登记资源，未保存草稿与尚未登记的外部新增文件不包含在内；没有主动推送，AI 想看最新内容需再次调用。文本/Markdown、字幕、CSV、JSON、HTML 与 SVG 正文作为纯文本返回；Word、图片、音频、视频等只返回资源信息，不读取大体积媒体或转换文档。

仅提供项目概要、资源分页查询、资源读取、绑定技能查询、绑定技能读取五个只读工具。MCP 无写文件、执行脚本、打开任意路径或推进交接基线的能力；只读凭据不能用于工作台编辑 API。固定收藏始终读项目绑定的版本，未固定的旧绑定按调用读取当前源 SKILL.md。正文视为资料，不作为执行命令的授权。

凭据仅由用户点击“复制 MCP 配置”时返回，不显示在页面或日志。`mcp-access.json` 保存在私有应用数据目录；同项目重新开启复用凭据，关闭即拒绝新请求，授权其他项目会轮换凭据。重启仍需重新开启；不要公开粘贴这份配置。云端或其他设备无法直接连接本机 127.0.0.1。

采用 JSON-only Streamable HTTP，兼容 2025-03-26、2025-06-18、2025-11-25 的初始化和 2026-07-28 的逐请求元数据/发现协议。无 SSE、订阅与协议 session。每页最多 48 条，文本文件最大 1 MiB，每次最多返回 16000 字符，HTTP 请求最大 128 KiB、响应最大 256 KiB，最多接受两个在途 MCP 请求。私密配置、数据库、日志、链接文件及其他项目内容不提供。限制不影响映序原有文档阅读与编辑。

## 自动更新

工作台就绪后后台检查官方版本，跨重启每日节流。Windows 可以后台下载不超过 50 MiB 的变化文件，完成后提醒保存文稿并退出安装；更大下载需要确认，安装保留原有退出保护及回退事务。不会强制结束进程，不静默改成下载完整包。可分别关闭自动检查和自动下载。详见 [增量更新](incremental-updates.md)。

macOS 此阶段自动发现新版本，尚未提供同等的自动安装流程；正式发布与各平台原生验收仍需分别完成。
