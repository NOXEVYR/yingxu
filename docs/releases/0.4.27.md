# 映序 0.4.27 · Windows 工作台与技能协作

版本身份为 `0.4.27 / calls.3`。本次把已封存并公开预览的改进整理为 Windows 交付，程序是否已发布以对应 Release 附件为准。

- 两种工作台共用数据和编辑器：原工作台保留固定资源导航，聚焦工作台按页面显示技能分类、标签或项目任务。切换保留编辑草稿与焦点。
- SKILL 库可直接搜索名称、说明、路径、个人标签和备注，管理收藏、分类及项目绑定的固定版本。搜索与来源、分类筛选共同生效。
- AI 协作把项目交接和 MCP 整理到右侧工具区，以页签切换并限制滚动高度；窄窗按需打开。任务、轮次、成果关联及可选外部工具入口继续使用原有权限与项目边界。
- 框选颜色随当前皮肤变化，避免默认黑白界面残留绿色。
- 构建使用新的原生启动器和锁定运行库；补齐完整包中的原生隔离启动源码，使随包源码可复建。文件级更新继续复用未变化运行库，不覆盖项目、技能库、数据库、配置或未登记文件。

Stage J 的合成页面截图与此前测试保留在预览说明。新 Windows EXE、完整包及其校验记录单独绑定本次源提交，不使用旧阶段 EXE 冒充新构建。尚未经长期真人使用验证，不新增“稳定版”标记。

macOS 0.4.20-mac.1 历史试用版保留。本次 Windows 交付不代表 Mac 已升级：当前 Mac 验证器仍有 0.4.25 版本检查，后续必须修正并完成平台构建及验收才可发布新的 Mac 附件。
