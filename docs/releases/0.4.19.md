# Windows 0.4.19

- 修复资源管理器双击兼容目录联接中的 Markdown、文本等文件时，误报“拖出路径包含联接或符号链接”的问题。显式打开、已有窗口接收、快速阅览与转入工作台使用同一真实文件路径；应用内文件选择器同样处理兼容目录。
- 素材拖出仍保留原有的路径限制。只读阅览不会改写原文件、编码或换行。
- 收录 Windows 按文件增量更新：手动检查后显示需下载的数据量，确认下载并退出应用后安装；复用未变化的运行库，校验每个文件，保留事务备份并支持失败恢复。无启动联网、后台常驻检查或新增模型和运行依赖。
- 旧版本首次获得增量功能需安装包含此功能的版本；后续发布包必须有配套清单。服务器不支持 Range、本机程序被修改或文件占用时明确停止，不自动下载整个包。
- macOS 仍使用完整包更新，本次修复针对 Windows 文件打开流程。

验证包含 Windows 原生构建与真实 WebView2 合成阅览测试，其中新增 20 项目录联接回归；使用隔离数据检查文本读取与原路径保存。具体安装包的摘要、来源提交及完整包验收记录以发布附件为准。
