# Windows 0.4.28 · 更新流程修补

修复检查完成后下载未启动、失败退避被每日节流覆盖、异常设置读取反复写状态，以及退出时中断的检查无法及时恢复。

改善网络路径不通时的连接回退，保留系统代理和 TLS 验证；减少官方附件重复跳转和 ZIP 文件头请求。无需修改系统网络设置，也不会退回下载完整包。

设置页补全后台更新状态、检查时间、重试时间和变化文件重试入口；打开设置期间也会跟随后台更新进度。页面启动请求暂时失败后会重新启动自动调度。

新增旧补丁缓存预览与确认整理，仅处理严格绑定成功安装事务并通过完整校验的旧下载缓存。当前计划、未知文件、项目、技能数据、安装备份和恢复记录保留。继续使用现有标准库与运行环境，没有新增运行依赖。

Windows 仍只后台下载不超过 50 MiB 的变化文件，更大更新需确认；安装继续保存、放弃、取消握手和进程退出检查。Mac 的自动安装仍未实现，公开包版本以对应平台附件为准。
