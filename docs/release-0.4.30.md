# 0.4.30 / xmind.2 思维导图工作区

本轮重建 XMind 编辑器。导图从静态主题树改为独立画布，提供左右／向右布局、曲线分支、双击直接编辑、原生文字选择复制、分支大纲复制、缩放和平移、折叠、搜索、大纲面板、属性面板、备注、字体与配色、分支移动和排序、多画布创建与改名、快捷键与撤销重做。

活动 XMind 标签通过已有可信页面消息关闭 WebView 的页面缩放；Ctrl／⌘＋滚轮由导图消费，围绕鼠标缩放。回到普通文稿或关闭标签时恢复应用缩放。导图比例限制为 20%～400%，普通滚轮平移，空白拖动／中键／空格拖动平移。相机、折叠和历史只存于当前标签，不写入 XMind 归档。

主题文字输入即同步草稿。中文输入期间阻止切换画布、结构变更和退出；Enter 完成编辑，Shift+Enter 换行，Esc 恢复编辑前文字。Ctrl+S 沿用原保存与备份。节点文字可拖选后正常复制；选中节点时 Ctrl+C 复制主题，Ctrl+Shift+C 复制带缩进的分支大纲。文本粘贴至画布可创建主题，Tab 缩进转换为层级。

分支移动保留 ID、后代、未知字段和原附件。禁止中心主题、概要主题及循环父子移动，继续遵守 5000 个主题／64 层／100 个画布限制。导图只按视口挂载可见主题，避免大文件一次创建全部节点控件。

主题样式使用 XMind SDK 的 `style.properties`、`fo:font-size`、`fo:font-weight`、`fo:font-style`、`fo:color` 与 `svg:fill` 字段；编辑指定属性时保留其他样式字段。显示支持这些安全属性及主题模板；不加载外部字体、图片或链接。富文本备注保留原格式，纯文本备注可编辑。旧版 XML 仍只读。

图像附件、关系线、概要和范围边界的原生绘制、自由主题任意坐标排版、富文本备注编辑仍未提供；原数据保留。不要将此工作区宣传为完整 XMind 客户端替代品。摘要和复杂范围结构的增删请使用原客户端。

Windows 和 macOS 构建须绑定同一来源提交，使用现有手动候选流程。此文档不改变正式下载入口或授权公开发布。macOS 14+ arm64 构建流程保留，实际 Mac 原生验收未执行。
