# 从文件夹导入项目

此功能已加入源码，尚未包含在 0.4.15 发布包中。

在项目库中选择归属分类，再把 Windows 文件夹拖到左侧“项目库”按钮。松手后会复制到设置中的项目存放位置，按“项目库分类 / 项目名称 / 资源分类”保存；复制和校验完成后，项目出现在左侧列表并打开。一次可拖入最多 20 个文件夹，每个文件夹作为一个项目。

也可以打开项目库，点击“从文件夹导入项目”，选择文件夹或填写本机绝对路径。浏览器或旧桌面宿主无法读取拖拽路径时，会显示这个入口，不会把文件夹当成空文件上传到当前项目。

- “文本、素材、角色、场景、道具、预演、生成素材、成片交付、记录、未分类”等目录自动对应资源分类；兼容旧版映序的 `00_Brief`、`20_Assets` 等布局，以及“剧本、文档、白模预演、参考资料”等旧名称。
- 根目录的 Markdown、文本、Word、PDF 放入“文本”。用途不明确的文件和目录保留层级，放入“未分类”；不会猜测图片中的角色或场景。
- 子文件夹、空文件夹和普通辅助文件一同复制；资源列表只索引映序支持的文件类型。分类后可识别的 Markdown 本地链接会调整到副本位置，原文稿不改写。其他格式内的自定义路径可能需要手动调整。
- 原文件夹保留；后续编辑只修改项目副本。同一路径再次拖入会打开已有副本，不覆盖修改、不恢复已删除条目，也不把来源变动自动同步到副本。若对应项目在回收站中，请先恢复。
- 同名项目另建目录；分类归并后的同名文件冲突会明确报错，不覆盖。复制中途失败不登记不完整项目，已提交后索引失败可在项目中手动刷新。
- 单次每项目最多 20,000 个文件或目录、20 层、约 5,000 个文件夹、64 GiB 总量，单文件最多 16 GiB。拒绝联接、符号链接和硬链接，以及磁盘根、用户目录、应用数据目录和复制到自身内部。

只有拖入或主动选择文件夹时才执行复制与索引；复用已有后台队列，不新增启动扫描、定时监控、模型或运行依赖。
