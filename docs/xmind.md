# XMind 思维导图

0.4.29 新增 `.xmind` 支持，0.4.30 重建为独立思维导图工作区。Windows 与 macOS 使用同一离线解析器和画布，无新增运行依赖。正式下载入口仍指向已发布并核验的历史包。

在项目资源区空白处、分类、文件夹或左侧项目上右键，选择“新建 XMind 思维导图”，输入名称。文件保存到操作时选中的项目和文件夹，名称用作中心主题。已有同名文件会自动编号，不覆盖原文件。

使用“导入文件”、拖放或粘贴文件导入 `.xmind`；也可用“打开本地文件”直接打开。默认复制到项目，原件保留；引用模式遵循原有引用规则。XMind 是独立文件，不会当作普通 ZIP 解压。

新版 XMind 的 `content.json` 支持多画布切换、新建及改名、双击直接编辑主题、文字选择与复制、分支大纲复制、文本粘贴生成层级、子主题和同级主题、确认删除、撤销与重做。属性面板支持纯文本备注、字号、加粗、斜体和配色；分支可通过右下角手柄或属性区移动、排序。Ctrl+S / ⌘S 保存，未保存草稿、输入法组词和退出确认沿用文稿保护。保存前备份原文件，并校验外部修改；其他画布、未知 JSON 字段、样式文件和附件原字节保留。

Ctrl / ⌘＋滚轮只缩放当前导图，支持 20%～400%、适应窗口和定位主题。普通滚轮平移；拖动画布空白、中键拖动或空格拖动可平移。支持左右／向右布局、分支折叠、搜索并定位隐藏主题，以及可收起的大纲和属性区。Tab 添加子主题，Enter 添加同级，F2 编辑，Ctrl+Z 撤销，Ctrl+Shift+Z 重做。直接编辑时 Enter 完成、Shift+Enter 换行、Esc 取消。

界面提供可操作的主题结构和基础样式，不重现 XMind 的精确布局、关系线、概要、范围边界、富文本备注或附件画面；这些信息仍保留在文件中。复杂排版与附件编辑继续使用 XMind。旧版 `content.xml` 提供只读预览，可缩放、搜索和复制，请在 XMind 中另存为新版格式后编辑。具体实现及验收边界见 [0.4.30 交付说明](release-0.4.30.md)。

单文件最多 32 MiB，正文最多 2 MiB，解压数据合计最多 64 MiB；最多 100 个画布、5000 个主题、64 层。读取不解压到磁盘，不加载外部链接；损坏、加密、重复或越界成员会明确报错。

生成格式参照 [XMind 官方 SDK](https://github.com/xmindltd/xmind-sdk-js)，采用 `content.json`、`metadata.json`、`manifest.json` 包结构。未宣称已用人工安装的 XMind 客户端验证全部版本兼容性。
